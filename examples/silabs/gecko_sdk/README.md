# Silicon Labs Gecko SDK — EFR32BG22 Explorer Kit

Silicon Labs I2C implementation of the `lcd_intfc` and `delay` interfaces, targeting the
[EFR32BG22 Explorer Kit](https://www.silabs.com/development-tools/wireless/bluetooth/bg22-explorer-kit?tab=overview)
with Gecko SDK 4.4.5.

---

## Hardware

| Item | Value |
|---|---|
| Board | Silicon Labs BG22 Explorer Kit (SLTB010A) |
| MCU | EFR32BG22C224F512IM40 |
| SDK | Gecko SDK 4.4.5 |

---

## I2C Interface Configuration

The I2CSPM component is configured with a single instance named **`lcd1602`**.

| Setting | Value |
|---|---|
| Peripheral | I2C0 |
| SCL | Port D, Pin 2 (PD02) |
| SDA | Port D, Pin 3 (PD03) |
| Speed mode | Standard — 100 kbit/s |
| Reference clock | 0 (use current system clock) |
| I2CSPM instance name | `lcd1602` |

---

## Simplicity Studio Setup

1. Open your project in Simplicity Studio 5.
2. Go to **Software Components** and install **I2C Simple Poll-based Master (I2CSPM)**.
3. Add an instance named **`lcd1602`**.
4. In the **Pin Tool**, assign PD02 to SCL and PD03 to SDA for the `lcd1602` instance.
5. Save — Studio generates `autogen/sl_i2cspm_init.c` and `autogen/sl_i2cspm_instances.h`.
   Reference copies of these files are in `auto_generated/` for documentation purposes only;
   do not add them to the build.

---

## Integrating lcd_intfc

`lcd_intfc_init()` owns I2C initialisation. After setting up the I2CSPM component, edit
`autogen/sl_event_handler.c` inside `sl_driver_init()`:

```c
// Replace:
sl_i2cspm_init_instances();

// With:
lcd_intfc_init();   // lcd_intfc_init() calls sl_i2cspm_init_instances() internally
```

Add `#include "lcd_intfc.h"` to the includes block in the same file.

> **Note:** `sl_event_handler.c` is regenerated by Simplicity Studio on component changes.
> Re-apply this edit after each regeneration.

## Low-Power Notes

`lcd_intfc_teardown()` and `lcd_intfc_bringup()` are implemented in `lcd_intfc.c` but are
**not wired to any sleep hooks** in the example application. For a fork that removes the LCD
and targets EM2 deep sleep with BLE advertising:

- Call `lcd_intfc_teardown()` before `sl_power_manager_sleep()` (or in an EM2 pre-sleep hook).
- Call `lcd_intfc_bringup()` on wake before any I2C access.
- Set `SL_DEVICE_INIT_EMU_EM2_DEBUG_ENABLE 0` in `sl_device_init_emu_config.h` for production
  builds — the default value of `1` keeps PD0B powered in EM2 for the debugger, adding
  ~50–100 µA to the EM2 idle current.

With BLE advertising at a 1–5 s interval and debug disabled, the EFR32BG22 can sustain
average currents in the 5–20 µA range.
